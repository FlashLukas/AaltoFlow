# Flyers

One-page flyers for AaltoFlow and some of its parts. Each is a PDF (one tall
page, text and links selectable) and the same page as a PNG.

| Flyer | What it covers | |
|---|---|---|
| **AaltoFlow** | the suite: modules, launcher, scan engine, data viewer | [PDF](AaltoFlow-flyer.pdf) · [PNG](AaltoFlow-flyer.png) |
| **Camera** | laser-spot tracking, sample stabiliser, autofocus | [PDF](AaltoFlow-Camera-flyer.pdf) · [PNG](AaltoFlow-Camera-flyer.png) |
| **clMag** | electromagnet field control in mT | [PDF](AaltoFlow-clMag-flyer.pdf) · [PNG](AaltoFlow-clMag-flyer.png) |
| **KIM stage** | KIM101 piezo inertia stage in steps or um | [PDF](AaltoFlow-KIM-flyer.pdf) · [PNG](AaltoFlow-KIM-flyer.png) |
| **Navigator** | a GDS layout or an image registered to the stage: click and go | [PDF](AaltoFlow-Navigator-flyer.pdf) · [PNG](AaltoFlow-Navigator-flyer.png) |

Each flyer says which parts have been tested on hardware and which only in
simulation. The screenshots are of the real software; the ones taken on the
lab setup say so in their captions.
